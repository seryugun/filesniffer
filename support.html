Frequently asked questions

How do I get started?

  1. Click Target Folders in the toolbar.
  2. Click + and choose a folder (for example Downloads). Indexing starts right away.
  3. Type in the search field. Results update as you type.

On first launch, an on-screen guide walks you through adding a folder and the main buttons.

A file doesn't appear in the search results.

  1. Make sure the folder containing the file is added in Target Folders.
  2. If it is, click Refresh.
  3. Check that the name isn't matched by a rule in Exclusions.

Mac: Some folders (Mail, Messages, and so on) aren't searched.

macOS protects these folders. To include them:

  1. Click Open Settings… at the bottom of the Target Folders window (or open System Settings > Privacy & Security > Full Disk Access).
  2. Turn on FileSniffer.
  3. Restart the app.

This permission is optional; the folders you choose are indexed without it.

Mac: I can't rename an app (.app) or move it to the Trash.

Turn on FileSniffer in System Settings > Privacy & Security > App Management.

Windows: Deleted files don't go to the Recycle Bin.

Network drives and some removable drives have no Recycle Bin. For items on these drives, FileSniffer asks before deleting them immediately. Items deleted this way can't be restored, so check the list before you confirm.

Windows: How do I find files with the same content?

  1. Click Target Folders in the toolbar.
  2. Turn on Find files with the same content (hashdupe:) at the bottom of the window.
  3. Type hashdupe: in the search field.

FileSniffer reads file contents in the background to compare them, so the first check can take a while with many files or on network drives. Only files that have been checked appear in the results.

Files on an external drive disappeared.

When a drive is disconnected, its target folder is shown as not found and its files are removed from the list. When you connect the drive again, the folder is indexed again automatically.

Changes made while the app was closed aren't shown.

Live watching works only while the app is running. Click Refresh, or set an Auto-Index interval.

How do I rename many files at once?

  1. Select several items in the results.
  2. Right-click and choose Rename….
  3. Replace text found in every name, or add text before or after the names. You can also add numbers in list order.
  4. Check the new names in the preview, then click Rename. File extensions don't change.

To stop while renaming, click Renaming… in the status bar and confirm. Items already renamed keep their new names, and the rest keep their original names.

Where can I learn the search syntax?

  1. Open Help in the app (⌘? on Mac, F1 on Windows).
  2. Choose "Search Syntax and Examples". It lists the operators, wildcards, and functions with examples.

자주 묻는 질문

어떻게 시작하나요?

  1. 툴바의 대상 폴더를 누릅니다.
  2. +를 눌러 폴더(예: 다운로드)를 고릅니다. 바로 색인이 시작됩니다.
  3. 검색창에 입력합니다. 입력하는 대로 결과가 바뀝니다.

처음 실행하면 화면 안내가 대상 폴더 추가부터 주요 버튼까지 차례로 보여 줍니다.

검색 결과에 파일이 나오지 않아요.

  1. 툴바의 대상 폴더에 그 파일이 들어 있는 폴더가 추가되어 있는지 확인하세요.
  2. 추가되어 있다면 새로 고침을 누르세요.
  3. 제외 목록에 해당 이름이 들어 있지 않은지 확인하세요.

Mac: 일부 폴더(메일, 메시지 등)가 검색되지 않아요.

macOS가 보호하는 폴더입니다. 검색에 넣으려면:

  1. 대상 폴더 창 아래쪽의 설정 열기…를 누릅니다(또는 시스템 설정 > 개인정보 보호 및 보안 > 전체 디스크 접근 권한).
  2. FileSniffer를 켭니다.
  3. 앱을 다시 시작합니다.

이 권한은 선택 사항이며, 켜지 않아도 고른 폴더는 색인됩니다.

Mac: 앱(.app)의 이름을 바꾸거나 휴지통으로 옮기지 못해요.

시스템 설정 > 개인정보 보호 및 보안 > 앱 관리에서 FileSniffer를 켜세요.

Windows: 삭제한 파일이 휴지통으로 가지 않아요.

네트워크 드라이브와 일부 이동식 드라이브에는 휴지통이 없습니다. 이런 드라이브의 항목은 즉시 삭제할지 먼저 묻습니다. 즉시 삭제한 항목은 되돌릴 수 없으니 목록을 확인한 뒤 진행하세요.

Windows: 내용이 같은 파일을 찾고 싶어요.

  1. 툴바의 대상 폴더를 누릅니다.
  2. 창 아래쪽의 내용이 같은 파일 찾기 (hashdupe:)를 켭니다.
  3. 검색창에 hashdupe:를 입력합니다.

파일 내용을 백그라운드에서 읽어 비교하므로, 파일이 많거나 네트워크 드라이브에 있으면 처음 확인에 시간이 걸릴 수 있습니다. 확인이 끝난 파일만 결과에 나옵니다.

외장 드라이브의 파일이 사라졌어요.

드라이브를 분리하면 해당 대상 폴더는 "찾을 수 없음"으로 표시되고 목록에서 빠집니다. 다시 연결하면 자동으로 다시 색인됩니다.

앱이 꺼져 있는 동안 바뀐 파일이 반영되지 않아요.

실시간 감시는 앱이 실행 중일 때만 동작합니다. 새로 고침을 누르거나 자동 색인 주기를 설정하세요.

여러 파일의 이름을 한 번에 바꾸고 싶어요.

  1. 검색 결과에서 여러 항목을 선택합니다.
  2. 우클릭 메뉴의 이름 변경…을 고릅니다.
  3. 모든 이름에 들어 있는 문구를 바꾸거나 이름 앞뒤에 문구를 붙입니다. 목록 순서대로 번호도 매길 수 있습니다.
  4. 바뀔 이름을 미리 보고 이름 변경을 누릅니다. 파일의 확장자는 바뀌지 않습니다.

변경하는 동안 상태 표시줄의 일괄 변경 중… 표시를 클릭한 뒤 확인하면 중지됩니다. 이미 바뀐 항목은 그대로 두고, 남은 항목은 원래 이름으로 둡니다.

검색 문법을 알고 싶어요.

  1. 앱의 도움말을 엽니다(Mac은 ⌘?, Windows는 F1).
  2. "검색 문법과 예시"를 고릅니다. 연산자, 와일드카드, 함수와 예시가 정리되어 있습니다.

よくある質問

使い始めるには？

  1. ツールバーの 対象フォルダをクリックします。
  2. +をクリックしてフォルダ（例：ダウンロード）を選びます。すぐに索引の作成が始まります。
  3. 検索フィールドに入力します。入力に合わせて結果が更新されます。

初めて起動すると、対象フォルダの追加から主なボタンまで画面上のガイドが順に案内します。

検索結果にファイルが表示されません。

  1. そのファイルを含むフォルダが 対象フォルダに追加されているか確認してください。
  2. 追加されている場合は更新をクリックしてください。
  3. 除外リストにその名前が含まれていないか確認してください。

Mac：一部のフォルダ（メール、メッセージなど）が検索されません。

macOS が保護しているフォルダです。検索に含めるには：

  1. 対象フォルダウインドウ下部の設定を開く…をクリックします（またはシステム設定 > プライバシーとセキュリティ > フルディスクアクセス）。
  2. FileSniffer をオンにします。
  3. アプリを再起動します。

この権限は任意で、オンにしなくても選んだフォルダは索引されます。

Mac：アプリ（.app）の名前を変更したり、ゴミ箱に入れたりできません。

システム設定 > プライバシーとセキュリティ > アプリ管理で FileSniffer をオンにしてください。

Windows：削除したファイルがごみ箱に入りません。

ネットワークドライブや一部のリムーバブルドライブにはごみ箱がありません。こうしたドライブの項目は、すぐに削除するかを先に確認します。すぐに削除した項目は元に戻せないため、一覧を確認してから進めてください。

Windows：内容が同じファイルを探したいです。

  1. ツールバーの 対象フォルダをクリックします。
  2. ウインドウ下部の内容が同じファイルを探す（hashdupe:）をオンにします。
  3. 検索欄に hashdupe: と入力します。

ファイルの内容をバックグラウンドで読み込んで比較するため、ファイルが多い場合やネットワークドライブにある場合は、最初の確認に時間がかかることがあります。確認が終わったファイルだけが結果に表示されます。

外部ドライブのファイルが消えました。

ドライブを取り外すと、その対象フォルダは「見つかりません」と表示され、一覧から外れます。再接続すると自動的に索引が作成し直されます。

アプリを終了している間の変更が反映されません。

リアルタイム監視はアプリの実行中のみ動作します。更新をクリックするか、自動索引の間隔を設定してください。

複数のファイルの名前をまとめて変更したいです。

  1. 検索結果で複数の項目を選択します。
  2. 右クリックメニューの名前を変更…を選びます。
  3. すべての名前に含まれる文字列を置き換えるか、名前の前後に文字列を追加します。一覧の順に番号も付けられます。
  4. 新しい名前をプレビューで確認し、名前を変更をクリックします。ファイルの拡張子は変わりません。

変更中はステータスバーの一括変更中…をクリックして確認すると中止します。すでに変更した項目はそのまま、残りの項目は元の名前のままになります。

検索構文を知りたいです。

  1. アプリのヘルプを開きます（Mac は ⌘?、Windows は F1）。
  2. 「検索構文と例」を選びます。演算子、ワイルドカード、関数と例がまとめてあります。

常见问题

如何开始使用？

  1. 点按工具栏中的 目标文件夹。
  2. 点按 + 选择一个文件夹（例如"下载"），索引会立即开始。
  3. 在搜索栏中输入，结果会随输入即时更新。

首次启动时，屏幕引导会依次介绍如何添加文件夹以及主要按钮。

搜索结果中没有出现某个文件。

  1. 请确认包含该文件的文件夹已添加到 目标文件夹中。
  2. 如果已添加，请点按刷新。
  3. 请确认排除列表中没有包含该名称。

Mac：部分文件夹（邮件、信息等）无法被搜索。

这些是 macOS 保护的文件夹。要将它们加入搜索：

  1. 点按目标文件夹窗口底部的打开设置…（或前往 系统设置 > 隐私与安全性 > 完全磁盘访问权限）。
  2. 打开 FileSniffer。
  3. 重新启动 App。

此权限为可选项，不打开也会索引您选择的文件夹。

Mac：无法给 App（.app）重命名或将其移到废纸篓。

请在 系统设置 > 隐私与安全性 > App 管理 中打开 FileSniffer。

Windows：删除的文件没有进入回收站。

网络驱动器和部分可移动驱动器没有回收站。对于这些驱动器上的项目，FileSniffer 会先询问是否立即删除。立即删除的项目无法恢复，请确认列表后再继续。

Windows：如何查找内容相同的文件？

  1. 点按工具栏中的 目标文件夹。
  2. 打开窗口底部的查找内容相同的文件（hashdupe:）。
  3. 在搜索框中输入 hashdupe:。

FileSniffer 会在后台读取文件内容进行比较，文件较多或位于网络驱动器时，首次检查可能需要一些时间。只有检查完成的文件才会出现在结果中。

外置驱动器上的文件不见了。

断开驱动器后，对应的目标文件夹会显示为"找不到"，并从列表中移除。重新连接后会自动重新索引。

App 关闭期间的更改没有反映出来。

实时监视仅在 App 运行时工作。请点按刷新，或设置自动索引间隔。

如何一次重命名多个文件？

  1. 在搜索结果中选择多个项目。
  2. 从右键菜单中选取重命名…。
  3. 替换所有名称中都包含的文字，或在名称前后添加文字。还可以按列表顺序添加编号。
  4. 在预览中确认新名称，然后点按重命名。文件的扩展名不会更改。

重命名期间，点按状态栏中的正在批量重命名…并确认即可停止。已重命名的项目保留新名称，其余项目保留原名称。

在哪里可以了解搜索语法？

  1. 打开 App 的帮助（Mac 为 ⌘?，Windows 为 F1）。
  2. 选择"搜索语法和示例"，其中整理了运算符、通配符、函数及示例。

常見問題

首次啟動時，螢幕導覽會依序介紹如何加入資料夾以及主要按鈕。

搜尋結果中沒有出現某個檔案。

  2. 如果已加入，請按一下重新整理。
  3. 請確認排除清單中沒有包含該名稱。

Mac：部分資料夾（郵件、訊息等）無法被搜尋。

這些是 macOS 保護的資料夾。要將它們加入搜尋：

  1. 按一下目標資料夾視窗底部的打開設定…（或前往 系統設定 > 隱私權與安全性 > 完整磁碟取用權限）。

Windows：刪除的檔案沒有進入資源回收筒。

網路磁碟機和部分卸除式磁碟機沒有資源回收筒。對於這些磁碟機上的項目，FileSniffer 會先詢問是否立即刪除。立即刪除的項目無法復原，請確認清單後再繼續。

Windows：如何尋找內容相同的檔案？

  1. 按一下工具列中的 目標資料夾。
  2. 開啟視窗底部的尋找內容相同的檔案（hashdupe:）。
  3. 在搜尋框中輸入 hashdupe:。

FileSniffer 會在背景讀取檔案內容進行比較，檔案較多或位於網路磁碟機時，首次檢查可能需要一些時間。只有檢查完成的檔案才會出現在結果中。

外接磁碟上的檔案不見了。

中斷連接磁碟後，對應的目標資料夾會顯示為「找不到」，並從列表中移除。重新連接後會自動重新索引。

App 關閉期間的變更沒有反映出來。

即時監看僅在 App 執行時運作。請按一下重新整理，或設定自動索引間隔。

如何一次重新命名多個檔案？

  1. 在搜尋結果中選取多個項目。
  2. 從右鍵選單中選擇重新命名…。
  3. 取代所有名稱中都含有的文字，或在名稱前後加入文字。還可以依列表順序加上編號。
  4. 在預覽中確認新名稱，然後按一下重新命名。檔案的副檔名不會變更。

重新命名期間，按一下狀態列中的正在批次重新命名…並確認即可停止。已重新命名的項目保留新名稱，其餘項目保留原名稱。

在哪裡可以了解搜尋語法？

  1. 開啟 App 的說明（Mac 為 ⌘?，Windows 為 F1）。
  2. 選擇「搜尋語法與範例」，其中整理了運算子、萬用字元、函式及範例。
