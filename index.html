Complete toolkit

찾고, 확인하고,
바로 정리하세요.

단순한 파일명 검색을 넘어 색인 유지와 파일 작업까지 연결했습니다. 외장 디스크가 많거나 대규모 자료를 관리할수록 더 선명한 작업 흐름을 제공합니다.

01 INDEX

여러 대상 폴더를 하나의 색인으로

  • 내장 디스크, 외장 볼륨, 네트워크 폴더를 함께 색인
  • 새로 고침은 바뀐 항목만, 전체 색인은 처음부터 다시
  • 처음 실행하면 화면 안내로 주요 버튼 소개
02 LIVE

실시간 변경 감지

  • 생성, 삭제, 이름 변경, 수정 즉시 반영
  • 1분, 5분, 10분 등 주기별 자동 색인
03 SEARCH

정교한 검색 문법

  • AND, OR, NOT과 정규식
  • 와일드카드로 이름 일부 검색
  • 경로, 확장자, 크기, 날짜, 중복 조건
04 RESULTS

최대 50,000개 결과를 읽기 좋은 표로

  • 이름, 경로, 크기, 형식, 날짜로 정렬
  • 열 순서와 표시 여부 기억
  • 앱 아이콘으로 파일 종류를 한눈에
05 FILTERS

자주 쓰는 검색식 저장

  • 검색식에 이름을 붙여 저장
  • 클릭 한 번으로 다시 검색
  • 언제든 수정, 삭제
06 EXCLUDE

유연한 제외 규칙

  • *.txt, txt, 폴더명/ 형식 지원
  • 파일명, 확장자, 폴더 단위로 제외
  • 제외한 항목은 DB에서도 바로 정리
07 ACTIONS

검색 결과에서 바로 작업

  • 열기, Finder에서 보기
  • Space로 빠른 보기, 드래그 앤 드롭
  • 잘라내기, 복사, 붙여넣기
  • 목록에서 바로 이름 고치기
08 RENAME

여러 파일 이름을 한 번에 바꾸기

  • 여러 항목 선택 후 우클릭 → 이름 변경
  • 모든 이름에 들어 있는 공통 문구를 찾아 바꾸거나 지우기
  • 이름 앞뒤에 문구 붙이기, (001) 같은 번호 매기기
  • 확장자는 그대로, 바뀔 이름은 미리 확인
  • 겹치는 이름은 미리 차단, 진행 중에도 언제든 중지
09 DELETE

안전한 삭제 흐름

  • 확인 후 휴지통으로 이동
  • 휴지통이 없는 볼륨은 한 번 더 확인
10 PROFILES

목적별로 완전히 분리된 프로필

  • 업무, 사진, 영상처럼 용도별로 나누기
  • 대상 폴더, 색인 DB, 필터, 제외 규칙, 자동 색인 주기, 정렬을 따로 저장
  • 다른 프로필로 바꿔도 진행 중인 색인은 계속
11 LANGUAGES

다섯 가지 표시 언어

  • 시스템 언어 따르기 또는 직접 선택
  • 한국어, English, 日本語, 简体中文, 繁體中文
12 DUPLICATES

이름이 달라도 내용이 같은 파일 찾기

  • 검색창에 hashdupe:를 입력하면 내용이 똑같은 파일만 표시
  • hashdupe: video:처럼 다른 조건과 함께 사용
  • 대상 폴더 창에서 직접 켤 때만 동작, 기본값은 꺼짐
  • 파일 내용은 기기 안에서만 읽고 비교용 해시만 저장
13 THEME

밝게, 어둡게 테마

  • 시스템 설정 따르기, 밝게, 어둡게 중 선택
  • 도구 막대에서 바로 전환

한글 파일명은 디스크의 유니코드 저장 방식이 달라도 같은 이름으로 검색됩니다. 잘못된 값이나 지원하지 않는 함수는 상태 표시줄에서 알려 줍니다.

How it works

빠른 검색을 위한
단단한 내부 구조.

느린 파일 시스템 순회와 빠른 검색을 분리합니다. 폴더 스캔은 병렬로 진행하고, 데이터베이스 기록은 안전하게 순서대로 처리해 색인 중에도 검색할 수 있습니다.

폴더 선택보안 범위 북마크로 사용자가 허용한 위치를 기억합니다.
병렬 스캔여러 대상 폴더를 동시에 순회하며 숨김 파일과 패키지 내부를 건너뜁니다.
로컬 저장파일명과 경로, 크기, 형식, 날짜를 로컬 데이터베이스에 묶어서 기록합니다.
즉시 검색검색식을 SQL 조건으로 변환하고 최신 요청의 결과만 화면에 반영합니다.
Local by design

파일 정보는
기기 안에 머뭅니다.

색인 DB와 설정은 Mac이나 Windows PC 안에만 저장됩니다. 파일 내용은 내용이 같은 파일 찾기를 직접 켰을 때만 기기 안에서 읽고, 비교용 해시만 저장합니다. 사용자가 선택한 폴더만 접근하며, 대상 폴더가 사라지거나 외장 볼륨이 분리되면 상태를 명확하게 표시합니다.
