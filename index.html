Complete toolkit

찾고, 확인하고,
바로 정리하세요.

단순한 파일명 검색을 넘어 색인 유지와 파일 작업까지 연결했습니다. 외장 디스크가 많거나 대규모 자료를 관리할수록 더 선명한 작업 흐름을 제공합니다.

01 INDEX

여러 대상 폴더를 하나의 색인으로

내장 디스크, 외장 볼륨, 네트워크 위치에서 원하는 폴더를 여러 개 추가합니다. 새 항목과 사라진 항목만 반영하는 최신 갱신, DB를 비우고 다시 만드는 전체 색인을 모두 지원합니다.

02 LIVE

실시간 변경 감지

선택한 폴더를 재귀적으로 감시해 생성, 삭제, 이름 변경, 수정을 색인에 반영합니다. 1분, 5분, 10분 또는 사용자 지정 간격의 자동 갱신도 제공합니다.

03 SEARCH

정교한 검색 문법

AND, OR, NOT, 묶기, 정확 일치, 와일드카드, 정규식, 경로와 확장자, 크기와 날짜, 중복 탐색까지 하나의 검색창에서 조합합니다.

04 RESULTS

최대 20,000개 결과를 읽기 좋은 표로

파일 이름, 전체 경로, 크기, 형식, 생성 날짜와 수정 날짜를 정렬합니다. 열 순서와 표시 여부는 그대로 기억되며, 파일은 기본 앱 아이콘으로 빠르게 구분됩니다.

05 FILTERS

자주 쓰는 검색식 저장

검색식을 이름과 함께 저장해 한 번에 다시 실행하고, 필요할 때 수정하거나 삭제합니다.

06 EXCLUDE

유연한 제외 규칙

*.txt, txt, 폴더명/처럼 파일명, 확장자, 폴더 규칙을 지정합니다. 제외 항목은 DB에서도 즉시 정리됩니다.

07 ACTIONS

검색 결과에서 바로 작업

열기, Finder에서 보기, Space 빠른 보기, 드래그 앤 드롭, 인라인 이름 변경, 공통 앞부분을 바꾸는 일괄 이름 변경을 지원합니다.

08 DELETE

안전한 삭제 흐름

선택한 항목을 확인 후 휴지통으로 이동합니다. 볼륨에 휴지통이 없을 때만 별도 확인을 거쳐 즉시 삭제합니다.

09 PROFILES

목적별로 완전히 분리된 프로필

업무, 사진, 영상처럼 프로필을 나누면 대상 폴더, 색인 DB, 저장 필터, 제외 규칙, 자동 갱신 주기와 정렬 상태가 각각 독립적으로 유지됩니다. 다른 프로필의 색인 작업은 전환 후에도 이어집니다.

10 LANGUAGES

다섯 가지 표시 언어

시스템 설정, 한국어, English, 日本語, 简体中文, 繁體中文 중에서 앱 언어를 선택할 수 있습니다.

How it works

빠른 검색을 위한
단단한 내부 구조.

느린 파일 시스템 순회와 빠른 검색을 분리합니다. 폴더 스캔은 병렬로 진행하고, SQLite 쓰기는 안전하게 직렬화해 색인 중에도 검색할 수 있습니다.

폴더 선택보안 범위 북마크로 사용자가 허용한 위치를 기억합니다.
병렬 스캔여러 대상 폴더를 동시에 순회하며 숨김 파일과 패키지 내부를 건너뜁니다.
로컬 저장파일명과 경로, 크기, 형식, 날짜를 SQLite DB에 배치로 기록합니다.
즉시 검색검색식을 SQL 조건으로 변환하고 최신 요청의 결과만 화면에 반영합니다.
Local by design

파일 정보는
Mac 안에 머뭅니다.

색인 DB와 설정은 로컬에 저장됩니다. 사용자가 선택한 폴더만 접근하며, 대상 폴더가 사라지거나 외장 볼륨이 분리되면 상태를 명확하게 표시합니다.
