FileSniffer Privacy Policy

FileSniffer does not collect personal information.

English

Effective date: October 28, 2026

FileSniffer ("the app") does not collect personal information. This policy applies to both the macOS and Windows versions.

1. Information we collect

None. The app does not collect personal information or send it to the developer or any third party. It uses no advertising, analytics, or tracking, and makes no network connections.

2. Information handled on your device

  • File list (index): the names, paths, sizes, creation and modification dates, and kinds of the files and folders inside the folders you choose are stored in a database on your device (Mac or Windows PC) only. The app reads file contents only when you turn on Find files with the same content below.
  • Find files with the same content (optional, off by default): only when you turn this on in the Target Folders window, the app reads, on your device, the contents of files that have the same size as another file, and calculates CRC-32 and SHA-256 hashes (short values used to compare contents). Only the hashes are stored in the index database. File contents themselves are never stored or sent off your device, and the original contents cannot be recovered from the hashes. When you turn it off, the app stops reading file contents.
  • Settings: target folders, saved filters, exclusions, profiles, sort order and columns, display language, and theme are stored only on your device.
  • None of this information leaves your device.

3. Feedback email

When you click Send Feedback, a new message opens in your mail app with the app version, operating system (macOS or Windows) version, and display language filled in. It is sent only if you review and send it yourself, and messages we receive are used only to answer you.

4. Permissions

  • Folders you choose: the app accesses only the folders you select.
  • Full Disk Access (macOS, optional): lets the app index file names in folders macOS protects. File contents are read only when Find files with the same content is on.
  • App Management (macOS, optional): lets the app rename apps (.app) or move them to the Trash when you ask.

5. Deleting your information

  • Removing a target folder deletes its index, including its hashes.
  • Rebuilding the index deletes all stored hashes along with the index.
  • Deleting a profile deletes its settings and index.
  • Deleting the app deletes everything it stored (the app container on macOS, the app data on Windows).

6. Children's privacy

The app collects no personal information from anyone.

7. Changes

Changes to this policy will be posted on this page with a new effective date.

  • October 28, 2026: added the optional Find files with the same content feature and the Windows version.

한국어

시행일: 2026년 10월 28일

FileSniffer(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다. 이 방침은 macOS판과 Windows판에 함께 적용됩니다.

1. 수집하는 정보

앱은 개인정보를 수집하거나 개발자 또는 제3자에게 전송하지 않습니다. 광고, 분석(애널리틱스), 추적 도구를 사용하지 않으며 네트워크 통신을 하지 않습니다.

2. 앱이 기기 안에서 다루는 정보

  • 파일 목록(색인): 사용자가 직접 고른 대상 폴더 안의 파일과 폴더의 이름, 경로, 크기, 생성일, 수정일, 파일 형식을 사용자의 기기(Mac 또는 Windows PC) 안의 데이터베이스에만 저장합니다. 파일의 내용은 아래의 내용이 같은 파일 찾기를 켠 경우에만 읽습니다.
  • 내용이 같은 파일 찾기(선택, 기본값 꺼짐): 사용자가 대상 폴더 창에서 이 기능을 켠 경우에만, 크기가 같은 다른 파일이 있는 파일의 내용을 기기 안에서 읽어 CRC-32와 SHA-256 해시(내용을 비교하기 위한 짧은 값)를 계산합니다. 계산한 해시만 색인 데이터베이스에 저장하며, 파일 내용 자체는 저장하거나 기기 밖으로 보내지 않습니다. 해시로는 원래 내용을 되살릴 수 없습니다. 기능을 끄면 더 이상 파일 내용을 읽지 않습니다.
  • 설정: 대상 폴더, 저장한 필터, 제외 목록, 프로필, 정렬과 열 구성, 표시 언어, 테마를 사용자의 기기 안에만 저장합니다.
  • 이 정보는 기기 밖으로 나가지 않습니다.

3. 피드백 메일

사용자가 피드백 보내기를 누르면 사용자의 메일 앱에서 새 메일이 열립니다. 본문에는 앱 버전, 운영체제(macOS 또는 Windows) 버전, 앱 표시 언어가 미리 채워집니다. 메일은 사용자가 직접 확인하고 보낼 때만 전달되며, 받은 메일은 문의에 답하는 데만 사용합니다.

4. 권한

  • 사용자가 고른 폴더: 앱은 사용자가 선택한 폴더에만 접근합니다.
  • 전체 디스크 접근 권한(macOS, 선택): 켜면 macOS가 보호하는 폴더의 파일 이름도 색인할 수 있습니다. 파일 내용은 내용이 같은 파일 찾기를 켠 경우에만 읽습니다.
  • 앱 관리(macOS, 선택): 켜면 사용자가 요청할 때 앱(.app)의 이름을 바꾸거나 휴지통으로 옮길 수 있습니다.

5. 정보 삭제

  • 대상 폴더를 제거하면 그 폴더의 색인과 해시가 삭제됩니다.
  • 전체 다시 색인하면 저장된 해시도 색인과 함께 삭제됩니다.
  • 프로필을 삭제하면 그 프로필의 설정과 색인이 삭제됩니다.
  • 앱을 삭제하면 앱이 저장한 모든 정보(macOS는 앱 컨테이너, Windows는 앱 데이터)가 함께 삭제됩니다.

6. 어린이의 개인정보

앱은 어떤 사용자에게서도 개인정보를 수집하지 않습니다.

7. 변경

이 방침이 바뀌면 이 페이지에 게시하고 시행일을 고칩니다.

  • 2026년 10월 28일: 선택 기능인 내용이 같은 파일 찾기와 Windows판에 대한 내용을 추가했습니다.

  • ファイル一覧（索引）：ユーザーが選んだ対象フォルダ内のファイルとフォルダの名前、パス、サイズ、作成日、変更日、種類を、ユーザーのデバイス（Mac または Windows PC）内のデータベースにのみ保存します。ファイルの内容は、下記の内容が同じファイルを探すをオンにした場合にのみ読み取ります。
  • 内容が同じファイルを探す（任意、初期設定はオフ）：ユーザーが対象フォルダウインドウでこの機能をオンにした場合にのみ、サイズが同じほかのファイルがあるファイルの内容をデバイス内で読み取り、CRC-32 と SHA-256 のハッシュ（内容を比較するための短い値）を計算します。データベースに保存するのは計算したハッシュだけで、ファイルの内容そのものを保存したり、デバイスの外に送ったりすることはありません。ハッシュから元の内容を復元することはできません。オフにすると、ファイルの内容は読み取らなくなります。
  • 設定：対象フォルダ、保存したフィルタ、除外リスト、プロファイル、並べ替えと列の構成、表示言語、テーマを、ユーザーのデバイス内にのみ保存します。

4. 権限

  • ユーザーが選んだフォルダ：本アプリはユーザーが選択したフォルダにのみアクセスします。

  • 対象フォルダを削除すると、そのフォルダの索引とハッシュが削除されます。
  • 索引を再作成すると、保存されたハッシュも索引とともに削除されます。
  • プロファイルを削除すると、そのプロファイルの設定と索引が削除されます。
  • 本アプリを削除すると、本アプリが保存したすべての情報（macOS ではアプリのコンテナ、Windows ではアプリのデータ）が削除されます。
