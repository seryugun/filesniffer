Complete toolkit

Find it, check it,
sort it out.

FileSniffer goes beyond file name search, keeping the index current and letting you work with files right in the results. The more external disks and data you manage, the clearer the workflow gets.

01 INDEX

Many target folders, one index

  • Index internal disks, external volumes, and network folders together
  • Refresh updates only what changed; Rebuild Index starts over
  • An on-screen guide shows the main buttons on first launch
02 LIVE

Live change tracking

  • Picks up creates, deletes, and renames
  • Auto-Index every 1, 5, or 10 minutes
03 SEARCH

Precise search syntax

  • AND, OR, NOT, and regular expressions
  • Wildcards to match part of a name
  • Path, extension, size, date, duplicates
04 RESULTS

Up to 50,000 results in a clear table

  • Sort by name, path, size, kind, or date
  • Column order and visibility are remembered
  • App icons show each file's type at a glance
05 FILTERS

Save frequent searches

  • Save a search expression with a name
  • Run it again with one click
  • Edit or delete it anytime
06 EXCLUDE

Flexible exclusions

  • Rules like *.txt, txt, folder/
  • Leave out names, extensions, or folders
  • Excluded items are removed from the DB
07 ACTIONS

Act right from the results

  • Open, Show in Finder
  • Quick Look with Space, drag and drop
  • Cut, Copy, and Paste
  • Rename right in the list
08 RENAME

Rename many files at once

  • Select several items, right-click, and choose Rename…
  • Find text common to every name, then replace or remove it
  • Add text before or after names, or numbers like (001)
  • Extensions stay as they are; preview new names first
  • Duplicate names are blocked, and you can stop at any time
09 DELETE

Safe deletion

  • Confirm, then move to the Trash
  • Asks again on volumes with no Trash
10 PROFILES

Fully separate profiles for each purpose

  • Split by purpose, such as work, photos, and video
  • Each keeps its own folders, index DB, filters, exclusions, Auto-Index, and sorting
  • Indexing continues even after you switch profiles
11 LANGUAGES

Five display languages

  • Follow the system language or pick one
  • 한국어, English, 日本語, 简体中文, 繁體中文
Search language

Type a little,
narrow it down exactly.

Search by path, kind, size, date, and folder structure as well as by name. Double quotes mean an exact match, and a trailing slash means everything inside the matching folder.

Practical examples

*.mp4 size:>1gbMP4 files over 1 GB
<"Travel/"|"Family/"> file:*.movMOV files in two folders
image: dm:thismonthImages modified this month
dupe:Find possible duplicates
!temp ext:pdf;docxDocuments without "temp"

What's supported

Space, & AND| OR! NOT< > GROUP" " EXACT*, **, ?file:folder:path:parent:ext:kind:size:dm:dc:depth:child:regex:case:wholeword:dupe:sizedupe:audio:video:image:doc:

Names stored in decomposed Unicode, such as Korean, are found as the same name. Invalid values and unsupported functions are reported in the status bar.

How it works

A solid core
built for fast search.

Slow file system scans are kept apart from fast searches. Folders are scanned in parallel, and database writes are safely handled in sequence, so you can search while indexing.

Choose foldersSecurity-scoped bookmarks remember the locations you allow.
Parallel scanTarget folders are scanned at the same time, skipping hidden files and package contents.
Local storageNames, paths, sizes, kinds, and dates are saved to the local database in batches.
Instant searchSearch expressions become SQL conditions, and only the latest results are shown.
Local by design

Your file information
stays on your Mac.

The index DB and settings are stored locally. Only the folders you choose are accessed, and FileSniffer clearly shows when a target folder disappears or an external volume is disconnected.
